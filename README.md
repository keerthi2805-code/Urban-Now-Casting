# Urban Nowcasting System 🌧️

### Real-Time Street-Level Urban Flood Nowcasting System

Urban Nowcasting System is a prototype system designed to predict and visualize urban flood risk at the street level and support safer navigation during heavy rainfall.

The system combines rainfall information, terrain, drainage conditions, and road-network data to provide localized flood-risk insights for the next 0–3 hours.

## Features

- 🌧️ Real-time flood-risk visualization
- 🗺️ Interactive GIS map using Mapbox
- 🛣️ Street-level flood-risk identification
- 📍 Location-based flood monitoring
- 🚗 Flood-aware navigation
- 🔮 What-If rainfall simulation
- ⚠️ Flood severity and drainage status
- 📊 Live flood-risk dashboard
